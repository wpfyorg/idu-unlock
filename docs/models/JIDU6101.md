# JIDU6101: install OpenWrt

The JIDU6101 is an Arcadyan-built MediaTek `6j01` router with official OpenWrt
support from 25.12.6. This repo mirrors the correct 6101 images, but installation
uses UART + TFTP because the available community factory UBI predates a critical
SPI-NAND write fix.

> [!TIP]
> `./flash.sh download` detects JIDU6101 and downloads + verifies the mirrored
> factory UBI, official initramfs, and official sysupgrade. Use the official
> initramfs + sysupgrade for the UART/TFTP install below.

> [!WARNING]
> Flashing replaces the stock firmware. Keep stable power and Ethernet connected
> until the router reboots. If the network unlock is closed on your stock build
> and root SSH is not already available, use the UART route instead.

## Why automatic SSH flashing is disabled

The mirrored factory UBI identifies correctly as `jiorouter_ax6000-jidu6101`,
but it is a community build from July 2026. OpenWrt merged the JioRouter
SPI-NAND write fix on 2026-09-11 in
[PR 25122](https://github.com/openwrt/openwrt/pull/25122). The factory UBI's
embedded device tree still has `bias-disable` on `SPI2_CS`, `SPI2_HOLD`, and
`SPI2_WP`, which is the exact configuration that fix replaces with pull-ups.

That means an automated factory-stage write can silently fail even when the
command reports success. The repo therefore keeps `6101` download support but
does not run that image as an SSH flasher stage.

Download and verify the mirrored files with:

```sh
./flash.sh download
# or directly:
./firmware/fwflash.sh 6101 --download-only
```

They are cached under `firmware/downloads/6101/`.

## UART + TFTP install

This route boots the official initramfs without first writing the stock flash,
then installs the official sysupgrade. Use it for recovery or when network root
access is unavailable.

### B1. Download and rename the files

Get the pair from the [firmware selector](https://firmware-selector.openwrt.org/).
For this model they are:

```text
openwrt-<version>-mediatek-filogic-jiorouter_ax6000-jidu6101-initramfs-kernel.bin
openwrt-<version>-mediatek-filogic-jiorouter_ax6000-jidu6101-squashfs-sysupgrade.bin
```

Rename them so the commands below stay short:

```sh
mv openwrt-*-jidu6101-initramfs-kernel.bin initramfs.bin
mv openwrt-*-jidu6101-squashfs-sysupgrade.bin sysupgrade.bin
```

### B2. Prepare the TFTP server and UART

Put `initramfs.bin` in the root of a TFTP server and give your PC the address
`192.168.1.2` on the Ethernet interface you will use. Connect the UART adapter
at **115200 8N1** and open the console.

### B3. Stop the boot

Power on the router. At the boot menu, select **Failsafe Mode**, then press
`Ctrl-C` to interrupt and reach the U-Boot prompt.
The 6101 normally reaches it without a login. If it asks for a username and
password, they are in `uboot_credentials.env` from your backup.

### B4. Boot the initramfs

At the U-Boot prompt:

```text
setenv ipaddr 192.168.1.1
setenv serverip 192.168.1.2
tftpboot 0x46000000 initramfs.bin
fdt addr $(fdtcontroladdr)
fdt rm /signature
bootm
```

`$(fdtcontroladdr)` is typed literally. `fdt rm /signature` removes the vendor
signature node, which is what lets the unsigned OpenWrt image boot.

Nothing is written to the flash in this step. If it fails, power-cycle and the
stock system is still there.

### B5. Install the sysupgrade

After about a minute the initramfs answers at `192.168.1.1`. From your PC, in
the folder with `sysupgrade.bin`:

```sh
scp -O sysupgrade.bin root@192.168.1.1:/tmp/
ssh root@192.168.1.1 "sysupgrade /tmp/sysupgrade.bin"
```

`unknown option -- O` means your `scp` is old; drop `-O` and retry. If SSH is
refused, open `http://192.168.1.1` and use **System → Backup / Flash Firmware →
Flash image…** with `sysupgrade.bin`. Do not tick *Keep settings*.

It writes the official image and reboots. Wait until it answers at
`192.168.1.1`, then set a root password.

## If it goes wrong

- **SSH is refused:** check that you are on `192.168.31.1` (stock) or
  `192.168.1.1` (temporary), and that Dropbear is running. If you skipped the
  unlock step, run `./flash.sh unlock` first.
- **TFTP times out:** check the PC address (`192.168.1.2`), the TFTP root, the
  firewall, and that the file is named exactly `initramfs.bin`.
- **`Bad FIT` or a signature error:** `fdt rm /signature` was missed, or
  `$(fdtcontroladdr)` was expanded by your shell. Type it literally.
- **No UART output:** check 3.3 V, TX/RX crossing, and 115200 8N1.
- **Sysupgrade fails:** do not power off halfway. If the flash was not touched,
  power-cycle back to stock. If it was, restore from the backup over UART.
- **UART pins:** No pin photo is published for this model. Identify the header
  before you connect anything.
- **Revert:** the backup has every partition. The
  [family FAQ](../../OPENWRT.md#faq) has the 6j01 restore steps, and the model
  pages have the per-model notes.
